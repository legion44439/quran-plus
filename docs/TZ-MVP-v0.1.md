# Quran Plus — ТЗ MVP v0.1
Дата: 2026-09-14  
Владелец продукта: Sanat  
Советник: QP Советник  
Координация разработки: CODE

## Решение
- Платформа: **только Android** (iOS позже)
- Sanat ведёт продукт с телефона (Honor); код — агенты + GitHub
- Контент добавляют модератор/админ, не публичные датасеты и не произвольные юзеры

## Роли
guest (опционально), user, moderator, admin, superadmin

## MVP (фаза 1) — делать сейчас
1. Auth: регистрация, вход, восстановление пароля
2. Коран: текст + аудио + поиск
3. Профиль пользователя
4. Web-админка: панели moderator / admin / superadmin; CRUD материалов
5. Стек ориентир: Flutter (Android), NestJS + PostgreSQL, Next.js admin

## Фаза 2 — после фазы 1
- Видео-лекции
- Статьи
- Офлайн-загрузка
- Счётчик просмотров
- Достижения (простые)
- Спонсор (без агрессивной рекламы у текста Корана)

## Вне скоупа MVP
- iOS
- Чаты / соц. лента
- Сложная монетизация

## Критерии готовности фазы 1
- Пользователь регистрируется и логинится на Android
- Читает и слушает Коран, есть поиск
- Видит профиль
- Модератор через web добавляет/правит материалы Корана (текст/аудио URL)
- Супер-админ назначает роли
